# personalsite.help

A community for personal websites. Share your site while it's still in
development, get structured feedback from designers and developers, and browse
everyone else's for ideas.

Personal sites only — if it doesn't belong on someone's homepage, it doesn't
belong here.

See [SPEC.md](SPEC.md) for the full product and technical spec.

## Stack

Vite · TanStack Router/Query · Convex · Clerk · shadcn/ui · Effect · oxlint/oxfmt · Cloudflare

## Status

Early development. Open source from day one.
